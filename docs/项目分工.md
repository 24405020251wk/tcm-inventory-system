# 项目分工与实施建议

## 一、五人分工

| 成员 | 角色 | 负责模块 | 代码位置 | 验收要点 |
| --- | --- | --- | --- | --- |
| 学生 1 | 权限与账号负责人 | 注册/登录/退出、用户管理、角色管理、菜单与接口权限 | `accounts/`、`core/permissions.py` | 3 个角色登录后菜单不同；越权访问返回 403；角色勾选菜单后即时生效 |
| 学生 2 | 档案负责人 | 药材档案 CRUD、分类管理、列表筛选排序分页、导出 | `herbs/` | 编码唯一；多条件筛选与排序正确；导出字段完整；有业务数据不可删除 |
| 学生 3 | 入库负责人 | 入库单主子表、明细动态增删、确认入库生成批次、单据查询 | `inbound/` | 草稿不影响库存；确认后批次与流水正确；批次号唯一 |
| 学生 4 | 出库负责人 | 领用申请、提交审核、审核/驳回、异常备注、历史追溯 | `outbound/` | 状态机完整；审核扣减近效期批次；库存不足拦截；越权 403 |
| 学生 5 | 统计负责人 | 库存查询、批次查询、统计图表、流水、操作日志、导出 | `inventory/`、`core/` | 查询条件组合正确；图表与列表数据一致；日志可追溯 |

> 交叉评审：每人需为**另一位成员**的模块写 2 条测试用例并执行，结果记录在 `docs/测试用例.md`。

## 二、协作方式（Git）

```bash
# 主分支保护，功能分支开发
git checkout -b feature/accounts-permission   # 学生 1
git checkout -b feature/herb-archive          # 学生 2
git checkout -b feature/inbound-batch         # 学生 3
git checkout -b feature/outbound-approval     # 学生 4
git checkout -b feature/inventory-stats       # 学生 5
```

提交信息建议：`feat(herbs): 支持按库存状态筛选`、`fix(outbound): 修复库存不足仍扣减的问题`。

冲突高发文件与约定：

| 文件 | 约定 |
| --- | --- |
| `config/settings.py` | 仅由组长修改，新增依赖先沟通 |
| `templates/base.html` | 侧边栏菜单由数据库驱动，避免手写菜单项 |
| `core/models.py` | 操作日志字段变更需通知全员 |
| `core/management/commands/init_demo.py` | 新增演示数据先合并到该命令，避免各自建库 |

## 三、建议排期（4 周）

| 周次 | 目标 | 交付物 |
| --- | --- | --- |
| 第 1 周 | 环境搭建、数据库设计、权限框架 | ER 图、表结构、登录与菜单权限可演示 |
| 第 2 周 | 档案 + 入库（含批次生成） | 可完成「新增药材 → 入库 → 看到批次库存」 |
| 第 3 周 | 出库审核 + 库存查询 | 可完成「领用 → 审核 → 库存扣减 → 流水」 |
| 第 4 周 | 统计图表、导出、日志、联调与答辩材料 | 演示脚本、测试用例、PPT、项目文档 |

## 四、答辩演示脚本（8 分钟）

1. **管理员登录**（1 分钟）：展示工作台指标、侧边栏 11 个菜单；进入「角色与权限」，说明菜单即权限点。
2. **仓管员登录**（2 分钟）：新增药材「砂仁」→ 新建入库单 2 条明细 → 确认入库 → 在药材详情展示自动生成的批次。
3. **普通员工登录**（1 分钟）：提交一张领用单（含异常备注），强调此时库存未变化。
4. **审核员登录**（2 分钟）：打开待审核单据 → 先演示库存不足被拦截（可临时改大数量）→ 修改后审核通过 → 展示库存减少、批次剩余量、流水记录。
5. **统计分析**（1 分钟）：分类占比、Top10、6 个月趋势、低库存与近效期预警。
6. **收尾**（1 分钟）：操作日志证明全流程留痕，回到 README 说明运行方式与测试结果。

## 五、评分自查表

- [ ] 项目可在助教电脑上用 `pip install -r requirements.txt` + 两条命令启动
- [ ] 5 个模块各有 3 个以上可演示、可测试的功能点
- [ ] 权限控制有正例（有权限可进）与反例（无权限 403）
- [ ] 数据一致性：库存 = 批次剩余量之和；每次变动有流水
- [ ] 至少 1 处异常处理（库存不足、重复批次号、删除保护）
- [ ] 有分页、筛选、排序、导出等实用功能
- [ ] 文档齐全：README、数据库设计、功能说明、测试用例
- [ ] 代码规范：模型 verbose_name、视图分层、模板继承、无硬编码密码
